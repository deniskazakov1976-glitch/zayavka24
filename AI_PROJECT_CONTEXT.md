# Заявка 24/7 — Архитектура и контекст проекта для ИИ-анализа

## 1. Назначение системы
**«Заявка 24/7»** — автономный ИИ-менеджер по продажам для сфер автобизнеса (детейлинг-центры, кузовной ремонт, автосервисы, тюнинг-ателье).
Система непрерывно квалифицирует лидов из входящих каналов (**Авито**, **WhatsApp Web**, **Telegram**), определяет марку авто и повреждения по тексту и фото, ориентирует клиента по прайс-листу и вилке цен, извлекает валидный номер телефона и мгновенно создает сделку в CRM (**amoCRM**, **Битрикс24**) или отправляет пуш мастеру-приемщику в рабочий Telegram-чат.

---

## 2. Ключевой стек технологий
* **Бэкенд & Веб:** Python 3.12+, FastAPI, Uvicorn, Jinja2, Starlette.
* **База данных:** SQLite в режиме WAL (с готовым скриптом миграции на PostgreSQL `scripts/migrate_sqlite_to_postgres.py`).
* **Telegram Bot:** Aiogram 3.x (мультитенантный пул ботов `BotManager` с индивидуальными токенами для каждого клиента).
* **LLM Engine:** OpenAI / OpenRouter / DeepSeek API (интеграция в `app/llm.py` с поддержкой Tool Calling: `capture_lead`, `record_knowledge_gap`, `ask_clarification`).
* **Безопасность & Авторизация:** PBKDF2-HMAC-SHA256 (соль на пользователя), HttpOnly Cookie-сессии, защита от брутфорса / rate-limiting по IP.
* **Веб-сервер & TLS:** Caddy Reverse Proxy (автоматический HTTPS Let's Encrypt / ZeroSSL для `*.sslip.io`).
* **Фронтенд:** Vanilla JS + Modern Responsive CSS (Glassmorphism, Dark Mode, мобильный sticky bar, интерактивный симулятор диалога, калькулятор ROI).

## 3. Архитектура модулей (`app/`)
* `server.py` — фабрика приложения FastAPI `create_app()`, подключение роутеров, монтирование статики и жизненный цикл (lifespan).
* `main.py` — точка входа сервиса: инициализация конфигурации, базы данных, хранилища компаний, Telegram-ботов и запуск Uvicorn.
* `auth.py` — сервис аутентификации, хеширование паролей, управление сессиями `zayavka_session`, роли:
  * `platform_admin` — владелец платформы (полный доступ ко всем тенантам, клиентам, финансам);
  * `client_admin` — клиент платформы (доступ строго изолирован своим `tenant_slug`);
  * `client_viewer` — сотрудник клиента (только чтение).
* `storage.py` — слой работы с SQLite:
  * Хранение пользователей, сессий, тенантов (`tenants`, `users`, `user_sessions`);
  * Диалоговые сессии (`chat_sessions`, `messages`);
  * Лиды (`leads`) с дедупликацией по номерам телефонов;
  * Пробелы в знаниях нейросети (`knowledge_gaps`) для дообучения;
  * Учет расхода токенов и биллинг (`llm_usage`, `model_prices`).
* `dashboard.py` — веб-панель управления и REST API:
  * Маршруты `/login`, `/logout`, `/`, `/onboarding`, `/landing`;
  * API лидов, диалогов, компаний, аналитики, базы знаний, онбординга новых клиентов;
  * Эндпоинты симулятора `/api/simulator/chat` и сбора лидов с лендинга `/api/landing/lead`.
* `company_store.py` — загрузчик YAML-профилей автосервисов (`companies/*.yaml`), определяющих прайс-лист, тон общения, город и перечень услуг.
* `bot_manager.py` & `telegram_bot.py` — диспетчеризация мультитенантных Telegram-ботов (уведомления мастерам, интерактивные кнопки, обработка медиа).
* `avito.py` — интеграция с Avito Messenger API v3: вебхуки входящих сообщений, отправка ответов, пауза при ручном ответе менеджера.
* `whatsapp.py` — интеграция с WhatsApp Web / GreenAPI: поддержка диалогов и парсинг телефонов.
* `llm.py` & `prompt_builder.py` — сборка системного промпта с защитой от инъекций (Prompt Injection Guard), прайс-листом компании и правилами квалификации.
* `crm.py` — коннекторы к amoCRM и Битрикс24 (отправка лида, создание сделки, тегирование контакта).
* `media_reply.py` — анализ фото повреждений автомобиля через мультимодальные модели (Vision).

## 5. Важные правила безопасности для анализа
* В архиве **намеренно исключен файл `.env`** и реальная база данных `data/bot.db` во избежание утечки API-токенов и персональных данных клиентов (152-ФЗ).
* Для конфигурации используется `.env.example`.
* Все конфиденциальные пароли и ключи хранятся в защищенном виде и не коммитятся в Git.

## 6. Недавние обновления архитектуры, надежности и безопасности (152 теста 100% PASS)
* **Каскадный Multi-Model Failover (`app/llm.py`, `app/config.py`):** настроена цепочка моделей `cx/gpt-5.6-luna` (OpenAI GPT-5.6 Mini/Luna) → `gc/gemini-2.5-flash` → `cx/gpt-6-luna`. Клиент работает с `max_retries=0`, мгновенно переключаясь при ошибках 503/429/timeout без зависания бота.
* **Умный контекстный оффлайн-движок (`build_contextual_fallback`):** при сбоях внешних API бот больше не задает слепых вопросов («какой у вас автомобиль?»). Модуль распознает марки и модели авто (`CAR_REGEX`), сопоставляет услугу с прайс-листом компании (`match_company_service`), рассчитывает точную вилку цен из YAML-профиля, обрабатывает график работы и скидки, а также аварийно захватывает телефон в `LeadInfo`.
* **Автоматизация деплоя на VPS (`scripts/deploy_to_server.py`):** беспарольный деплой по SSH-ключу, автоматическая изоляция и защита рабочей базы `data/bot.db`, безопасная упаковка проекта, автосборка Docker и HTTPS Caddy.
* **Студийный моушен-эксплейнер (`scripts/render_motion_promo.py`):** генератор Full HD 16:9 промо-ролика с векторной процедурной графикой (без битых эмодзи), spring-анимациями, EBU R128 аудиомастерингом (-14 LUFS) и встроенным видеоплеером в лендинг.
* **Изоляция в Telegram-боте:** команды `/leads`, `/pause`, `/resume`, `/forget` строго изолированы по компаниям клиента (`tenant_slug`), исключая просмотр чужих лидов. Команда `/reload` доступна только владельцу платформы. HTML-экранирование ответов защищает от сбоев Telegram API.
* **Безопасность API & Сеть:** отключен `allow_credentials` для глобального wildcard CORS `*`. В `client_ip()` приоритет отдан проверенному `X-Real-IP` от Caddy, защищая от подделки IP через `X-Forwarded-For`.
* **Защита от Stored XSS:** в `dashboard.html` строковая интерполяция в обработчиках событий заменена на изолированный реестр `window._gapQuestions` и `data-*` атрибуты.
* **Защита публичного симулятора:** `/api/simulator/chat` разрешает только белые демо-профили и обрезает сообщения истории до 1000 символов.
* **Кабинет и тарификация:** починен эндпоинт паузы сессий, сохранение выбранного тарифа при создании клиента и корректная остановка ботов при удалении тенанта.
* **Мультитенантный Авито и WhatsApp:** роутинг вебхуков привязан к компаниям, проверка квот тарифа выполняется ДО вызова Vision и генерации ответов.
* **Guardrails цен:** исправлен парсер множителей `×1000` для выражений «5 тыс», «15к», исключая пропуск неавторизованных цен.
* **Миграции БД:** синхронизированы все 17 таблиц SQLite для переноса в PostgreSQL (`scripts/migrate_sqlite_to_postgres.py`).
